# Brand & Site Blueprint

Before we design or code anything, I need to think through the foundation: the website owner's brand identity and the core pages this site needs.

Here's what I'm working with:

Platform: Loveable (a no-code/low-code builder)

Goal: Create a portfolio website that authentically represents the owner

Current stage: Planning phase — I haven't decided on structure or pages yet

Help me explore these questions:

Brand Identity: What should I understand about the portfolio owner to make smart design choices? (For example: their profession/field, the impression they want to make, their audience, their unique positioning or style, any specific values or aesthetic they want to project.) Help me think through what brand elements matter most for a portfolio.

Core Pages: What pages does a portfolio website genuinely need to work? Given the owner's field and audience, what's the minimum set of pages that serves their purpose, and what might be optional? Help me think through which pages earn their place.

Loveable Constraints: Are there any structural or design considerations specific to building in Loveable that I should factor into this plan?

I'm not looking for a finished sitemap yet — I'm looking to think through the decisions that come first. Surface the key questions I should answer about the brand and the core trade-offs in page structure so I can make the right choices before building.
